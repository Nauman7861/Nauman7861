## 📌 Featured projects

### [Student Feedback Sentiment Analysis](https://github.com/Nauman7861/student-feedback-sentiment-analysis) · MSc dissertation
NLP pipeline that sorts 44,516 student comments into positive, negative or neutral. It compares seven models, from VADER to fine-tuned DistilBERT and RoBERTa plus an ensemble, with the ensemble scoring best at **82.5% accuracy**. It also shows that applying SMOTE before cross-validation inflates scores by 14–17 points.
`Python` `scikit-learn` `PyTorch` `Hugging Face` `NLTK` `Streamlit`

### [Sensore: Pressure-Ulcer Monitoring Platform](https://github.com/Nauman7861/sensore-pressure-monitoring) · team of 4
Django + React app that turns 32×32 pressure-sensor data into live heat maps, alerts and reports for patients, clinicians and admins. **I owned authentication and role-based access control:** JWT login, token revocation on logout, and patient–clinician data isolation, covered by 23 API tests.
`Django REST Framework` `React` `TypeScript` `MySQL` `JWT`

### [Suraksha Net: Crime Management System](https://github.com/Nauman7861/Suraksha-Net) · team lead
Case-management and crime-analysis system for law enforcement, with role-based access to criminal records.
`PHP` `MySQL` `JavaScript`

### [AutoGrader](https://github.com/Nauman7861/AutoGrader)
Automated answer grading: OCR to extract answers and BERT-based NLP to score them, with over 80% grading accuracy.
`React` `Flask` `MongoDB` `BERT` `spaCy`
